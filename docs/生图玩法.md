# 🎨 生图与自拍 · 玩法与配置笔记

> omnidraw 插件的"生产级"配置经验——让机器人既能画任意画面，又能拍出"她本人"。
> 指令速查见《指令手册》；踩坑细节见《踩坑合集》#19。

## 一、两条链路，各司其职

| 链路 | 指令 | 干什么 | 建议模型 |
|---|---|---|---|
| 画图 `chain_text2img` | `/画 xxx` | 文生图：任意画面 | 免费：`Kwai-Kolors/Kolors`、`black-forest-labs/FLUX.1-schnell`；质量档：`Qwen/Qwen-Image` |
| 自拍 `chain_selfie` | `/自拍 场景` | 以角色立绘为参照，把"她"放进场景（图生图） | 保真档：`Qwen/Qwen-Image-Edit-2509` |

要点：**画图 ≠ 自拍**——画图凭文字凭空创作（角色不固定）；自拍会拿参考图 + 人设描述"锁住长相"，每张都是同一个娃。两条链路可以指向**不同的模型节点**，免费的和保真各就各位、互不打扰。

## 二、自拍的三件套

1. **人设描述**（`persona_base_prompt`）：按角色设定集写（外貌/发型/服装细节）；
2. **参考图**（`persona_ref_image`）：1~3 张"长相锚点"（推荐正面立绘）；
3. **图生图模型**：`Qwen/Qwen-Image-Edit-2509` 这类"保持角色、只改场景"的编辑模型。

### 参考图放哪（踩坑结论）

- 配置外层字段要写 **`files/<键路径文件夹>/文件名`** 形式（如 `files/persona_config/persona_ref_image/xxx.png`），文件放在 `plugin_data/<插件名>/files/…` 下；
- 人设模板**内部**字段不校验路径，可以直接写插件数据目录内的**绝对路径**；
- 报 `Invalid file path` = 路径格式不对（详见《踩坑合集》#19）。

## 三、base_url 必须写全路径（重要）

很多"OpenAI 兼容"的生图服务（如硅基流动）**没有 `/images/edits` 端点**——它的图生图是 `/images/generations` 带 `image` 参数。
把 provider 的 `base_url` 直接写完整端点 `https://api.siliconflow.cn/v1/images/generations`，插件会自动切换通道（原理见《踩坑合集》#19）。

## 四、调参经验

- **副脑（提示词优化器）**：中文模型（Kolors / Qwen 系）可以关掉（`enable_optimizer=false`），原生中文直出更稳；
- **风格预设**（`optimizer_style`）：有「日系插画大师 / 3D 潮玩盲盒 / 手机日常原生感…」——卡通角色**别用**"手机日常原生感"（它会拼命真实化，直接恐怖谷）；
- **热切换**：`/切换模型 画图/自拍 [序号]`、`/切换链路 目标 node_1/node_2`（管理员用，序号从 0 开始）。

## 五、素材与授权

若参考图取自社区项目（如 [YunYueSama/codex-deepseek-pet](https://github.com/YunYueSama/codex-deepseek-pet) 的角色立绘）：
遵守其「大肥鱼项目署名许可 1.0」——**可自由使用/商用，注明作者 + 仓库地址即可**；
⚠️ 其中被标注为"第三方参考、来源待核实"的素材（如某些梗图），别当作可再授权的资源使用。
