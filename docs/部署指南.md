# 部署指南

> 目标形态：一台 Windows 电脑 + QQ 小号 → 一只随时在线的 AI 鲸鱼娘。
> 本文只讲路线图和关键决策；每一步的具体安装包以各项目官方文档为准。

## 0. 路线总览

```
QQ 小号 ── NapCat（协议端，Windows）──┐
                                     ├─ WebSocket 6199
AstrBot（大脑，含插件/人格/记忆）───────┘
   ├── DeepSeek API（对话主力）
   ├── 阿里云百炼（眼睛/耳朵/嗓子：qwen3-vl / qwen3-asr / 音色复刻 TTS）
   └── 本地 Ollama（bge-m3 嵌入，记忆检索用，免费且不外传）
```

## 1. 装 AstrBot（大脑）

- 推荐用 **AstrBot Launcher**（图形化，隔离环境、托盘、开机自启）。
- 国内网络记得在「高级 → 通用」打开"中国大陆一键加速"（走中科大镜像）。

## 2. 装 NapCat（QQ 协议端）

- Windows 选 `NapCat.Shell.Windows.Node.zip`（自带 Node）。
- 首次启动扫码登录**小号**（强烈建议小号，有风控概率）。
- 启动脚本建议用 `launcher-win10-user.bat`（免管理员）。
- 在 WebUI（`http://127.0.0.1:6099`）或配置文件 `config/onebot11_<QQ号>.json` 里加一个
  **websocket 客户端**指向 `ws://127.0.0.1:6199/ws`（AstrBot 的反向 WS）。

## 3. AstrBot 里配三件套

| 提供商 | 用途 | 关键点 |
|---|---|---|
| DeepSeek (`deepseek-chat`) | 对话主力 | 官方 API `https://api.deepseek.com/v1` |
| 百炼视觉 (`qwen3-vl-plus`) | 图片/视频画面转述 | 填到"图片转述提供商" |
| 百炼语音 (`qwen-audio-3.1-tts-flash`) | 语音条 | 先在控制台做音色复刻拿 voice_id；⚠️ 还需两个源码补丁（踩坑 #15） |
| Ollama 嵌入 (`bge-m3`) | 记忆检索 | `ollama pull bge-m3`，本地免费 |

平台适配器选 **QQ(aiocqhttp)**，端口 6199。

## 4. 装插件与人格

- `plugin/astrbot_plugin_face_convert/` 整个文件夹丢进 `data/plugins/`，重启。
  （语音/视频理解依赖 `dashscope` SDK 与 `imageio-ffmpeg`，插件会自动用到；
   首次用到某功能报缺包按提示 `pip install` 即可。）
- 新建人格，把 `persona/大肥鱼-人格.md` 中 `---` 之后的**整段正文**粘进去，设为默认人格。
- 记忆/主动可装社区插件：`livingmemory`、`proactive_chat`（见 README 出处链接）。

> 📥 **人格 / 课程记忆 / 音色的手把手导入步骤，见 `docs/导入指南.md`。**

## 5. 安全设置（必做）

- AstrBot「访问控制」白名单：只放行你自己的会话（`qq:FriendMessage:<你的QQ>`）。
- 给机器人账号加好友需你手动通过——第一道门永远在你手里。
- 主动消息开"免打扰时段"（推荐 `23-8`，支持跨午夜写法）。
- 小号手机端偶尔挂着活跃，降低风控概率。

### 5.1 proactive_chat 低频私聊配方

- 私聊 `enable=true`，UMO 列表只放需要主动消息的会话，例如 `qq:FriendMessage:<你的QQ>`；
  UMO 可在私聊发 `/sid` 获取，别把群 UMO 混进来。
- 上下文来源 `conversation_history`；最小/最大间隔 `120/240` 分钟；最大未回复 `2` 次
  （连发两条没回复才暂停，等用户下次开口再恢复）。
- 免打扰 `23-8`。命中免打扰只会跳过并重新排期，不会在夜里发消息；
  插件重启后自动触发器沉默 30 分钟只是"建任务"，真正发送仍按 120～240 分钟随机间隔。

### 5.2 网页搜索（AnySearch 匿名额度）

- AstrBot 面板：配置文件 → AI → 能力 → 网页搜索；启用，提供商选 `anysearch`，
  API Key 留空即可使用匿名每日免费额度。
- 建议同时打开“显示来源引用”（`provider_settings.web_search_link=true`），方便核对链接。
- 对应配置键：`provider_settings.web_search=true`、`websearch_provider=anysearch`、
  `websearch_anysearch_key=[]`。改完需要重启 AstrBot。
- 验收别只听她说“我查过啦”：会话记录里应看到 `web_search_anysearch` 的 `tool_calls`
  和工具返回的官方链接。

### 5.3 主动消息也能联网找话题

主动消息插件默认直调 `provider.text_chat()`，不挂 `func_tool`，所以模型手里没有搜索工具。
用 `deploy/patches/proactive_chat/` 的两个补丁文件覆盖插件同名文件并重启，
主动消息就会按当前会话的 `provider_settings` 挂载 AnySearch，并执行“调用工具 → 带结果重问”的循环。
提示词末尾加一句“想聊新鲜话题时可先联网搜索”，模型会按需调用，不强制每条都搜。
验收：`docker logs astrbot | grep '工具 web_search_anysearch 执行完成'` 能看到实际调用。

## 6. 稳定性两件套（Windows 专属小心得）

- **合盖不睡**：`powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0`（交流/直流都设）。
- **连接看门狗**：NapCat 的 WS 断线不会自愈。用它的 WebUI API 写个"关了再开"的
  自愈脚本（原理见踩坑合集第 5 条），挂到计划任务或常驻进程里定时巡检。

## 7. 验证流程

1. 手机给机器人发"在吗" → 应回话（含表情）
2. 发一张图 → 她描述内容
3. 发一条语音 → 她复述你说的话
4. 聊十几轮 → 观察记忆召回（提一句"上次说的那事"）
5. 等 2～4 小时不聊 → 她可能主动冒泡（若开了 proactive，间隔按 120/240 分钟随机）
