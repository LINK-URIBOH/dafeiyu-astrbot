# 大肥鱼语速试听（2026-10-21）

这三段来自仓库现有的 `assets/voice-demo/大肥鱼-声音样本-M3.wav`，是同一段录音保持音高的变速对比，未调用 TTS 重新合成，也未修改线上声音配置。

| 文件 | 听感方向 | 处理 |
| --- | --- | --- |
| A-original.mp3 | 原来的节奏 | 保留原速度 |
| B-relaxed.mp3 | 稍放松 | 约慢 4%，atempo=1/1.04 |
| C-gentle.mp3 | 更舒缓 | 约慢 6%，atempo=0.98/1.04 |

音频均为 MP3、24 kHz、单声道、96 kbit/s，约 4.5–4.8 秒。音色来源与展示使用说明沿用上级目录 README。

手机使用：在浏览器打开文件直链；若没有自动播放，先保存 MP3，再用手机文件应用或音乐播放器打开。`voice-previews.zip` 包含三段 MP3 与本说明。

变速只能比较节奏。真实 TTS 调语速时可能重新改变停顿、重音与语调，不能把这三段视为对应 TTS 参数的实际合成效果。
