## v1.0.0 历史验收（2026-10-27）

- 当前固定 AstrBot 4.29.0 增量镜像中，50 项自动测试通过；本机无 AstrBot 的环境跳过其中 8 项框架集成测试。真实私聊测试发现命令需兼容唤醒阶段去除 `/`，且停止事件后不能依赖结果管道发送；已改为直接私聊发送，并添加对应框架回归测试。
- SDK 5.1.2 的直接安装与核心 cryptography 50.0.2 存在约束冲突，最终使用独立虚拟环境；构建校验核心 pip freeze 完全不变，两个环境的 pip check 均通过。
- 真实只读验证：DeepSeek 人民币余额返回成功；百炼 RAM 余额及完整分页账单查询成功，识别商品 sfm；硅基流动国内钱包接口返回成功，现金余额和金额比例通过用户参考值核对。
- 硅基流动累计消费未单独核对，因此使用现金余额差，不擅自合并代金券。
- 当前真实百炼返回的账单中存在跨越22点边界的汇总记录；严格按消费时间判断时不能精确归属该窗口，对应费用显示不可获取，余额和可用额度仍可展示。不以每日汇总或金额比例冒充目标窗口费用。
- 安装后的第一个完整22点窗口需要时间积累。自动边界、重启与持久化已用合成数据覆盖，不能将这些结果称为真实24小时费用已验收。

所有测试数据使用虚构账号和合成金额，无生产密钥、Cookie、余额及账单编号。真实验证结果只导出成功状态和能力边界，不公开财务数据。
