# B 站自主活动：源码检查与验收记录

记录日期：2026-10-21。本文区分代码实现、本地验证和真实环境验收。

**当前交付是待部署代码与操作脚本，尚未部署到用户的真实 AstrBot、Windows 或模拟器。没有完成真实 QQ 图片投递、B 站账号写操作或完整自主活动闭环。** 本地通过的测试不能替代这些验收。

候选项目要求 Node.js 22+，实际入口使用 `StdioServerTransport`。不能把它的本地 stdio 进程配置成云端 HTTP 地址。其现有读取接口、写操作重试方式、评论翻页/回复以及收藏夹管理覆盖程度不足以直接满足本次要求；扫码响应与凭证保存逻辑也需要适配。

本次选择独立的 Python 伴随服务，参考候选项目对应的 B 站接口，增加分页、回复、收藏夹管理、写操作账本和回读核实。**候选项目本身没有作为生产 MCP 服务接入。** 新服务通过真正的 MCP Streamable HTTP `/mcp` 提供工具，仅绑定 Windows 回环地址 `127.0.0.1:8010`。云端经 SSH 反向转发和 Docker 网关代理访问；已有 PhoneMCP 的 `8009/Phone` 链路保留。AstrBot 插件直接调用此 MCP，原始 `bili_execute` 等内部工具不得直接暴露给聊天模型。

新建服务下载总预算为每次准备最多 160 MiB，处理范围最多 300 秒、8 帧，返回媒体包最多 3 MiB。原始媒体与临时 ffmpeg 文件留在 Windows 处理并清理。截图使用独立压缩路径并保持文字可读；真实设备图像清晰度和 2 Mbit/s 链路耗时仍需测量。

截图的 OneBot `message_id` 和回读图片段只说明接口接受并可回读消息，**不等于主人已经在 QQ 打开图片**。一次性任务验收还要求实际图片打开确认。不得把 Windows 路径、base64 文本或“截图成功”当作图片验收。

候选项目已用锁文件安装依赖并执行构建和原有测试。候选项目结果日志位于开发环境 `/tmp/bilibili-build.log`、`/tmp/bilibili-test.log`。新增实现的最终测试次数、退出状态和回归记录由本次交付的验证报告列出；这里不将先前运行次数当作最终代码的验证结论。

`phone_screenshot.patch` 已针对上述 PhoneMCP 提交执行补丁适用性检查。补丁用于提高源截图 JPEG 质量，并在真实截图失败时返回错误，避免旧实现用黑图伪装成功。尚未应用到用户实际 PhoneMCP。Linux 中没有 PowerShell，Windows 启停脚本尚未执行。

## 实际联调阻塞与待验项目

当前 Codex 环境是 `/workspace` 下的隔离 Linux 开发环境。已检查的本机没有生产 `/opt/dafeiyu` 部署目录、可用生产 SSH 连接或 Windows/ADB 执行入口，不能复用仅存在于用户机器上的会话。仓库记录的 `/opt/dafeiyu`、Docker 网关和历史 QQ 私聊标识是线索，不能当作当前运行事实或接收人配置。

对 `https://api.bilibili.com/x/web-interface/nav` 的实际只读请求被本环境 HTTPS 代理拒绝，返回 `403 ClientHttpProxyError`。这是开发环境出口阻塞证据，不能据此断言用户 Windows 或云服务器无法访问 B 站。没有绕过代理、关闭 TLS 校验或输出账号凭证。

仍需真实运行入口才能完成：

1. 读取当前 AstrBot 部署位置、版本、当前人格、模型、主人私聊范围、免打扰设置、PhoneMCP 与 LivingMemory 配置；只报告必要非敏感项。
2. 备份并部署，核对依赖兼容，加载插件，验证同一真实模型能看到截图并收到工具结果。
3. 在用户 Windows 上启动伴随服务、复用现有 SSH 身份与连接路线建立独立 8010 转发，确认 `emulator-5554` 在线及界面识别。
4. 若现有凭证无法复用，再在运行环境生成登录二维码让用户扫码；凭证只落到运行目录，不进入聊天或日志。当前新服务保存刷新令牌但没有自动刷新流程，过期后需要重新扫码。
5. 实际读取所有要求的 B 站来源及分页；写操作先发具体提议，收到用户批准后执行、回读。不能用本地测试替代每项真实能力验收。
6. 先验收被动 QQ 截图，再创建数分钟后的一次性自主任务，验证自主截图、回执及分享后继续浏览；取得证据后才启用周期任务。

可靠身份提取目前不解析 `b23.tv` 短链接，也不从标题或评论猜测当前 BV。某些 B 站 App 页面可能不给出可读 BV/分 P，或 UI dump 因画面活动失败，此时返回未知；需要真实界面联调后补齐可验证的来源，不能将启动参数当作已经打开目标视频的证明。
